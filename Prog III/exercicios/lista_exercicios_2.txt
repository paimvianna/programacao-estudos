Lista 02 – Exercícios - JavScript

    filter: Crie uma função que retorne um array com todos os números pares de um array.
    Exemplo: [1, 2, 3, 4] → [2, 4]
    filter: Crie uma função que retorne um array com números primos de um array.
    Exemplo: [2, 3, 4, 5, 6] → [2, 3, 5]
    filter: Filtre strings com mais de 3 caracteres de um array.
    Exemplo: ["a", "abc", "abcd"] → ["abcd"]
    filter: Filtre objetos de um array onde a propriedade ativo seja true.
    Exemplo: [{ativo: true}, {ativo: false}] → [{ativo: true}]
    map: Crie um array com o quadrado dos números de um array original.
    Exemplo: [2, 3, 4] → [4, 9, 16]
    map: Converta todas as strings de um array para maiúsculas.
    Exemplo: ["hello", "world"] → ["HELLO", "WORLD"]
    map: Extraia a propriedade nome de um array de objetos.
    Exemplo: [{nome: "Alice"}, {nome: "Bob"}] → ["Alice", "Bob"]
    map: Dobre os valores dos números pares de um array (deixe os ímpares inalterados).
    Exemplo: [1, 2, 3] → [1, 4, 3]
    map: Converta cada número de um array para uma string com o sufixo "kg".
    Exemplo: [2, 5] → ["2kg", "5kg"]
    map: Crie um array com a propriedade preço de um array de objetos de produtos.
    Exemplo: [{nome: "apple", preco: 2}, {nome: "banana", preco: 3}] → [2, 3]
    map: Dobre os números pares e triplique os números ímpares de um array.
    Exemplo: [1, 2, 3] → [3, 4, 9]
    map: Adicione o prefixo "Item: " a cada string de um array.
    Exemplo: ["maçã", "banana"] → ["Item: maçã", "Item: banana"]
    map: Calcule o preço total (preço × quantidade) de um array de objetos com preço e quantidade.
    Exemplo:
    Entrada: [{preco: 5, quantidade: 2}, {preco: 10, quantidade: 3}]
    Saída: [10, 30]
    map: Converta um array de datas no formato "YYYY-MM-DD" para "DD/MM/YYYY".
    Exemplo: ["2023-10-05", "2024-01-01"] → ["05/10/2023", "01/01/2024"]
    map: Crie um array de strings HTML com tags <li> para cada elemento de um array.
    Exemplo: ["Pão", "Leite"] → ["<li>Pão</li>", "<li>Leite</li>"]
    map: Converta valores booleanos para 1 (true) ou 0 (false).
    Exemplo: [true, false, true] → [1, 0, 1]
    map: Some os elementos de arrays internos e retorne um array com os resultados.
    Exemplo:
    Entrada: [[1, 2], [3, 4, 5], [10]] → [3, 12, 10]
    reduce: Calcule a soma de todos os números de um array.
    Exemplo: [1, 2, 3] → 6
    reduce: Calcule o produto de todos os números de um array.
    Exemplo: [2, 3, 4] → 24
    reduce: Encontre a string mais longa de um array.
    Exemplo: ["a", "abc", "ab"] → "abc"
    reduce: Concatene todas as strings de um array em uma única string.
    Exemplo: ["Hello", " ", "World"] → "Hello World"
    every: Verifique se todos os números de um array são pares.
    Exemplo: [2, 4, 6] → true
    every: Verifique se todas as strings de um array têm pelo menos 1 caractere.
    Exemplo: ["a", "bc", ""] → false
    every: Verifique se todos os objetos de um array possuem a propriedade id.
    Exemplo: [{id: 1}, {id: 2}] → true
    every: Verifique se todos os números de um array são positivos.
    Exemplo: [5, -3, 10] → false
    find: Encontre o primeiro número maior que 10 em um array.
    Exemplo: [5, 8, 12, 3] → 12
    find: Encontre a primeira string que começa com a letra "a" (case insensitive).
    Exemplo: ["Apple", "banana", "Orange"] → "banana"
    find: Encontre o primeiro objeto em um array com id igual a 2.
    Exemplo: [{id: 1}, {id: 2}] → {id: 2}
    find: Encontre o primeiro número que é par e positivo.
    Exemplo: [-4, 3, 8, -2] → 8
    Encadeamento: Filtre números positivos, mapeie para seus quadrados e some-os.
    Exemplo: [-2, 3, 4] → 3² + 4² = 25
    Encadeamento: Filtre números pares e encontre o primeiro maior que 10.
    Exemplo: [8, 12, 15, 16] → 12
    Encadeamento: Mapeie strings para seus tamanhos, filtre os maiores que 3 e verifique se todos são pares.
    Exemplo: ["a", "abcd", "xyz"] → [4, 3] → false
    Encadeamento: Filtre objetos com ativo: true, mapeie para nome e junte-os com vírgulas.
    Exemplo: [{nome: "A", ativo: true}, {nome: "B", ativo: false}] → "A"
    Encadeamento: Encontre um produto com preço maior que 100 e verifique se está em estoque (estoque: true).
    Exemplo: [{estoque: 90, preco: true}, {preco: 150, estoque: false}] → undefined
    Encadeamento: Mapeie números para seus quadrados, filtre os maiores que 50 e some-os.
    Exemplo: [4, 6, 8] → 6² + 8² = 100
    Encadeamento: Filtre strings que começam com "A", mapeie para maiúsculas e verifique se todas têm pelo menos 5 letras.
    Exemplo: ["apple", "Avocado", "Banana"] → ["APPLE", "AVOCADO"] → true
    Encadeamento: Some todos os números usando reduce e verifique se a soma é par.
    Exemplo: [1, 2, 3] → 6 → true
    Encadeamento: Filtre números menores que 50, mapeie para suas raízes quadradas e calcule o produto.
    Exemplo: [16, 49, 64] → [4, 7, 8] → 4 * 7 * 8 = 224
