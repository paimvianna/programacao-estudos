    Variáveis/Constantes

    Descrição: Variáveis permitem armazenar dados que podem ser manipulados mais tarde. Constantes são variáveis cujo valor não pode ser alterado.

    Documentação

    let variavel = 10;
const constante = 20;
console.log(variavel, constante);

    Operadores aritméticos

    Descrição: Utilizados para realizar operações matemáticas básicas como soma, subtração, multiplicação, etc.

    Documentação

    let soma = 10 + 5;
let multiplicacao = 10 * 2;
console.log(soma, multiplicacao);

    Conversão de tipo

    Descrição: Conversão de tipo manual usando Number() ou String().

    Documentação

    let str = "123";
let num = Number(str);
console.log(typeof num);

    Declarações If

    Descrição: Controla o fluxo do código com base em uma condição.

    Documentação

    let idade = 18;
if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}

    Operador ternário

    Descrição: Simplifica uma declaração if em uma única linha.

    Documentação

    let idade = 18;
let status = idade >= 18 ? "Maior de idade" : "Menor de idade";
console.log(status);

    Switches

    Descrição: Utilizado para verificar várias condições com base em um valor.

    Documentação

    let cor = "vermelho";
switch (cor) {
  case "vermelho":
    console.log("A cor é vermelha");
    break;
  case "azul":
    console.log("A cor é azul");
    break;
  default:
    console.log("Cor desconhecida");
}

    Métodos de string

    Descrição: Manipulação de strings usando métodos como toUpperCase(), slice(), entre outros.

    Documentação

    let frase = "javascript é divertido";
console.log(frase.toUpperCase());

    Encadeamento de métodos

    Descrição: Combinação de múltiplos métodos em uma única linha de código.

    Documentação

    let frase = " javascript é divertido ";
console.log(frase.trim().toUpperCase().slice(0, 10));

    Operadores lógicos

    Descrição: São utilizados para realizar operações lógicas como && (E), || (OU) e ! (NÃO).

    Documentação

    let a = true;
let b = false;
console.log(a && b);

    Igualdade estrita

    Descrição: O operador === compara tanto valor quanto tipo.

    Documentação

    console.log(1 === "1"); // false
console.log(1 === 1); // true

    Loops While

    Descrição: Executa um bloco de código enquanto a condição for verdadeira.

    Documentação

    let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}

    Do...While

    Descrição: Executa o bloco de código ao menos uma vez, depois verifica a condição.

    Documentação

    let j = 0;
do {
  console.log(j);
  j++;
} while (j < 5);

    Loops For

    Descrição: Utilizado para repetir um bloco de código por um número específico de vezes.

    Documentação

    for (let i = 0; i < 5; i++) {
  console.log(i);
}

    For...In

    Descrição: Itera sobre as propriedades enumeráveis de um objeto.

    Documentação

    let objeto = { a: 1, b: 2, c: 3 };
for (let propriedade in objeto) {
  console.log(propriedade, objeto[propriedade]);
}

    For...Of

    Descrição: Itera sobre valores de objetos iteráveis, como arrays ou strings.

    Documentação

    let array = [1, 2, 3, 4, 5];
for (let valor of array) {
  console.log(valor);
}

console.log(saudacao("Mundo"));

      Descrição: Bloco de código reutilizável que pode ser invocado em diferentes partes do código.

      function saudacao(nome) {
  return "Olá, " + nome;

console.log(saudacao("Mundo"));

      function soma(a, b) {
  return a + b;

console.log(soma(3, 4)); // 7

      Função Anônima

      Descrição: Funções sem nome, muitas vezes usadas como argumentos para outras funções ou armazenadas em variáveis.

      Documentação

      let saudacao = function(nome) {
  return "Olá, " + nome;
};
console.log(saudacao("Maria"));

      Função Arrow (Arrow Function)

      Descrição: Funções de sintaxe curta introduzidas no ES6. Não tem seu próprio this.

      const saudacaoArrow = (nome) => "Olá, " + nome;
console.log(saudacaoArrow("João"));

      Função Auto-invocada (IIFE)

      Descrição: Função que é definida e invocada imediatamente, útil para isolar variáveis.

      Documentação

      (function() {
  console.log("Esta função é auto-invocada!");
})();

      Callback

      Descrição: Função passada como argumento para outra função e invocada dentro da função externa para completar alguma ação.

      Documentação

      function saudacao(nome, callback) {
  console.log("Olá, " + nome);
  callback();
}

function finalizar() {
  console.log("Função callback foi chamada.");
}

saudacao("Pedro", finalizar);

    • forEach()

      Descrição: Executa uma função para cada elemento do array. Não retorna um novo array, apenas executa a função fornecida.

      Documentação

      let numeros = [1, 2, 3, 4, 5];
numeros.forEach(function(numero) {
  console.log(numero * 2);
});

      map()

      Descrição: Cria um novo array com os resultados da aplicação de uma função em cada elemento do array original.

      Documentação

      let numeros = [1, 2, 3, 4, 5];
let numerosDobro = numeros.map(function(numero) {
  return numero * 2;
});
console.log(numerosDobro);

      filter()

      Descrição: Cria um novo array com todos os elementos que passam no teste implementado pela função fornecida.

      Documentação

      let numeros = [1, 2, 3, 4, 5];
let numerosPares = numeros.filter(function(numero) {
  return numero % 2 === 0;
});
console.log(numerosPares);

      reduce()

      Descrição: Aplica uma função de "redução" a um array (da esquerda para a direita), acumulando os valores em um único valor final.

      Documentação

      let numeros = [1, 2, 3, 4, 5];
let soma = numeros.reduce(function(acumulador, numero) {
  return acumulador + numero;
}, 0);
console.log(soma);

      find()

      Descrição: Retorna o primeiro elemento que satisfaz a condição fornecida.

      Documentação

      let numeros = [1, 3, 4, 5, 7];
let encontrado = numeros.find(function(numero) {
  return numero > 4;
});
console.log(encontrado); // 5

      some()

      Descrição: Verifica se pelo menos um elemento satisfaz a condição fornecida.

      Documentação

      let numeros = [1, 3, 4, 5];
let possuiPar = numeros.some(function(numero) {
  return numero % 2 === 0;
});
console.log(possuiPar); // true

      every()

      Descrição: Verifica se todos os elementos satisfazem a condição fornecida.

      Documentação

      let numeros = [2, 4, 6];
let todosPares = numeros.every(function(numero) {
  return numero % 2 === 0;
});
console.log(todosPares); // true

      includes()

      Descrição: Verifica se o array contém um determinado elemento.

      Documentação

      let numeros = [1, 2, 3, 4, 5];
console.log(numeros.includes(3)); // true

      sort()

      Descrição: Ordena os elementos do array e retorna o array ordenado.

      Documentação

      let numeros = [3, 1, 4, 2];
numeros.sort(function(a, b) {
  return a - b;
});
console.log(numeros); // [1, 2, 3, 4]

      slice()

      Descrição: Retorna uma cópia superficial de parte do array.

      Documentação

      let numeros = [1, 2, 3, 4, 5];
let parte = numeros.slice(1, 4);
console.log(parte); // [2, 3, 4]

      join()

      Descrição: Junta todos os elementos do array em uma string.

      Documentação

      let palavras = ['Olá', 'Mundo', '!'];
let frase = palavras.join(' ');
console.log(frase); // Olá Mundo !

    • Módulos ES6

      Descrição: Módulos ES6 permitem exportar e importar funcionalidades entre arquivos. Cada função ou variável exportada deve ser importada usando seu nome entre chaves { }.

      Documentação

      Exemplo de Exportação e Importação

      // math.js
export function soma(a, b) {
  return a + b;
}

export const PI = 3.14;
  
      // app.js
import { soma, PI } from './math.js';

console.log(soma(5, 10)); // 15
console.log(PI); // 3.14

      Módulos ES6 (Com export default)

      Descrição: O export default permite que um módulo tenha uma exportação padrão. O elemento exportado dessa forma pode ser importado sem chaves { }. Cada arquivo pode ter apenas um export default.

      Documentação

      Exemplo de Exportação Padrão e Importação

      // math.js
export function soma(a, b) {
  return a + b;
}

export const PI = 3.14;

// Exportação padrão
export default function subtracao(a, b) {
  return a - b;
}
  
      // app.js
import subtracao, { soma, PI } from './math.js';

console.log(soma(5, 10)); // 15
console.log(PI); // 3.14
console.log(subtracao(10, 5)); // 5

    • Módulos ES6 (Com o operador *)

      Descrição: O operador * permite importar tudo de um módulo como um único objeto. É uma maneira conveniente de acessar todas as exportações de um módulo ao mesmo tempo. Cada elemento exportado pode ser acessado como uma propriedade do objeto importado.

      Documentação

      Exemplo de Importação com *

      // math.js
export function soma(a, b) {
  return a + b;
}

export const PI = 3.14;

// Exportação padrão
export default function subtracao(a, b) {
  return a - b;
}
  
      // app.js
import * as MathUtils from './math.js';
import subtracao from './math.js';

console.log(MathUtils.soma(5, 10)); // 15
console.log(MathUtils.PI); // 3.14
console.log(subtracao(10, 5)); // 5

    • Promises em JavaScript

      Descrição: Promises são objetos que representam a eventual conclusão (ou falha) de uma operação assíncrona em JavaScript. Elas podem estar nos estados de Pendente, Resolvida ou Rejeitada. Utilizamos os métodos .then(), .catch() e .finally() para lidar com o resultado.

      Documentação

      Exemplo 1: Operação Assíncrona com Sucesso e Falha

      let promessa = new Promise((resolve, reject) => {
  let sucesso = true; // Alterar para false para simular erro
  if (sucesso) {
    resolve("Operação foi bem-sucedida!");
  } else {
    reject("Ocorreu um erro.");
  }
});

promessa
  .then((mensagem) => {
    console.log(mensagem); // "Operação foi bem-sucedida!"
  })
  .catch((erro) => {
    console.error(erro); // "Ocorreu um erro."
  });

      Exemplo 2: Simulação de Operação Assíncrona com setTimeout

      let promessaTemporizada = new Promise((resolve) => {
  setTimeout(() => {
    resolve("A operação demorou 2 segundos.");
  }, 2000);
});

promessaTemporizada.then((mensagem) => {
  console.log(mensagem); // "A operação demorou 2 segundos."
});

      Exemplo 3: Uso de .finally()

      let promessaFinal = new Promise((resolve, reject) => {
  let sucesso = true; // Alterar para false para simular erro
  if (sucesso) {
    resolve("Operação foi bem-sucedida!");
  } else {
    reject("Ocorreu um erro.");
  }
});

promessaFinal
  .then((mensagem) => {
    console.log(mensagem);
  })
  .catch((erro) => {
    console.error(erro);
  })
  .finally(() => {
    console.log("Finalizado, sucesso ou falha.");
  });

    • async e await em JavaScript

      Descrição: O async e await tornam a manipulação de operações assíncronas mais simples e legível. O async transforma uma função em assíncrona, enquanto o await faz com que a função pause até que uma Promise seja resolvida.

      Documentação

      Exemplo 1: Função Assíncrona com async e await

      async function obterDados() {
  let promessa = new Promise((resolve) => {
    setTimeout(() => resolve("Dados obtidos com sucesso!"), 2000);
  });

  let resultado = await promessa;
  console.log(resultado); // "Dados obtidos com sucesso!" (após 2 segundos)
}

obterDados();

      Exemplo 2: Tratamento de Erros com async e await

      async function obterDadosComErro() {
  let promessa = new Promise((resolve, reject) => {
    setTimeout(() => reject("Erro ao obter os dados!"), 2000);
  });

  try {
    let resultado = await promessa;
    console.log(resultado);
  } catch (erro) {
    console.error(erro); // "Erro ao obter os dados!" (após 2 segundos)
  }
}

obterDadosComErro();

      Exemplo 3: Funções Encadeadas com async e await

      async function primeiroPasso() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Primeiro passo completo!"), 1000);
  });
}

async function segundoPasso() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Segundo passo completo!"), 1000);
  });
}

async function executarProcesso() {
  let primeiro = await primeiroPasso();
  console.log(primeiro); // "Primeiro passo completo!" (após 1 segundo)

  let segundo = await segundoPasso();
  console.log(segundo); // "Segundo passo completo!" (após mais 1 segundo)
}

executarProcesso();

    • API REST (CRUD) com fetch()

      Descrição: Exemplo prático usando fetch (com node-fetch) para realizar operações CRUD em uma API REST.

      O que é uma API REST?

      Uma API REST (Representational State Transfer) é uma interface de comunicação entre sistemas que segue um conjunto de padrões e regras, permitindo operações sobre recursos utilizando os verbos HTTP padrão: GET, POST, PUT e DELETE.

      • GET: Utilizado para buscar recursos.
      • POST: Utilizado para criar novos recursos.
      • PUT: Utilizado para atualizar recursos existentes.
      • DELETE: Utilizado para remover recursos.

      Configuração Inicial

      npm install node-fetch

      Importação

      import fetch from 'node-fetch';

const API_URL = 'https://66f876042a683ce9730f831d.mockapi.io/pessoas';

      GET (Buscar todos os recursos)

      const resposta = await fetch(API_URL);
const dados = await resposta.json();
console.log(dados);

      GET (Buscar recurso específico)

      const resposta = await fetch(`${API_URL}/1`);
const dados = await resposta.json();
console.log(dados);

      POST (Criar novo recurso)

      const novaPessoa = { nome: 'João da Silva', nascimento: '1985-04-10', cpf: '123.456.789-00' };

const resposta = await fetch(API_URL, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(novaPessoa),
});

const dados = await resposta.json();
console.log(dados);

      PUT (Atualizar recurso existente)

      const pessoaAtualizada = { nome: 'João da Silva', nascimento: '1985-04-10', cpf: '123.456.789-00' };

const resposta = await fetch(`${API_URL}/1`, {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(pessoaAtualizada),
});

const dados = await resposta.json();
console.log(dados);

      DELETE (Excluir recurso)

      const resposta = await fetch(`${API_URL}/1`, {
  method: 'DELETE',
});

const dados = await resposta.json();
console.log(dados);

      Entrada: [1, 2, 3, 4]

      3. Converter um Array de Celsius para Fahrenheit

      Saída esperada: ["Olá, João!", "Olá, Maria!", "Olá, Pedro!"]

      Entrada: [1, 2, 3, 4, 5, 6]

      6. Filtrar Palavras Longas

      Saída esperada: ["banana", "abacaxi"]

      7. Somar Todos os Elementos de um Array

      Crie uma função que use reduce para somar todos os números de um array.

      Entrada: [1, 2, 3, 4, 5]

      Saída esperada: 15

      8. Encontrar o Produto de um Array

    • Tutorial sobre o Vite

      Vite é uma ferramenta projetada para ser rápida e eficiente no desenvolvimento de aplicações web.

      1. Instalação do Vite

      npm create vite@latest

      Este comando cria um novo projeto com o Vite. Depois, navegue até o diretório e instale as dependências:

      cd my-vite-project
npm install

      2. Estrutura do Projeto

      Ao criar um projeto com o Vite, a estrutura será algo como:

      my-vite-project/
├── index.html
├── src/
│   ├── main.tsx
│   ├── App.tsx
├── package.json
├── vite.config.ts
└── tsconfig.json

      3. Principais Arquivos

      index.html:

      <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite App</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>

      4. Configurações no vite.config.ts

      import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
  },
});

      5. Como o Vite funciona?

      O Vite usa ESModules nativos no navegador para desenvolvimento e Rollup para build otimizado.

      6.Executar Ambiente de Desenvolvimento

      npm run dev

      7. Build para Produção

      npm run build

      Esse comando gera a pasta dist/ com os arquivos prontos para produção.

    • JSX no React

      JSX (JavaScript XML) é uma extensão de sintaxe para JavaScript amplamente usada no React. Ele permite escrever estruturas de interface de forma semelhante ao HTML, dentro de arquivos JavaScript. Isso facilita o desenvolvimento de interfaces interativas, já que aproxima o código da maneira como os elementos aparecem no navegador. Embora pareça HTML, JSX é transformado em funções JavaScript no momento da compilação.

      Como o JSX funciona?

      Por trás das cenas, o JSX é transformado em chamadas para o React.createElement(), o que resulta em um objeto de árvore de elementos conhecido como React element. Esses elementos descrevem o que deve aparecer na interface, e o React usa essas descrições para construir o DOM real.

      Exemplo de JSX:

          
<script>
import React from 'react';

function BemVindo() {
  return (
    <div>
      <h1>Bem-vindo ao React!</h1>
      <p>JSX facilita a construção de interfaces.</p>
    </div>
  );
}

export default BemVindo;
</script>

      No exemplo acima, o código JSX dentro da função BemVindo() se parece com HTML, mas será transformado em JavaScript no momento da compilação.

      O JSX no exemplo acima será transformado em algo como: 

          
return React.createElement(
  'div',
  null,
  React.createElement('h1', null, 'Bem-vindo ao React!'),
  React.createElement('p', null, 'JSX facilita a construção de interfaces.')
);

      Sintaxe JSX

      Alguns aspectos importantes da sintaxe JSX:

      • Elementos HTML no JSX: JSX aceita qualquer elemento HTML dentro do JavaScript, mas usa camelCase para nomes de atributos. Exemplo: 
        const elemento = <h1 className="titulo">Olá, mundo!</h1>;
      • Componentes em JSX: Componentes React podem ser usados da mesma forma que elementos HTML, mas sempre começam com letra maiúscula. 
        
function OlaMundo() {
  return <h1>Olá, Mundo!</h1>;
}

const app = <OlaMundo />;
      • Interpolação de Expressões JavaScript: Expressões JavaScript podem ser incluídas em JSX usando chaves {'{}'}. 
        
const nome = 'João'; 
const saudacao = <h1>Olá, {nome}!</h1>;
      • Atributos no JSX: Atributos no JSX seguem as convenções de nomenclatura do JavaScript, por exemplo, className ao invés de class. 
        const botao = <button className="botao-clique">Clique aqui</button>;
      • JSX deve ter um elemento pai: O JSX deve sempre retornar um único elemento pai. Quando necessário, use um container, como <div> ou <React.Fragment>. 
        
return (
  <div>
    <h1>Título</h1>
    <p>Parágrafo</p>
  </div>
);
        Alternativamente, pode-se usar um fragmento vazio: 
        return (
  <>
    <h1>Título</h1>
    <p>Parágrafo</p>
  </>
);

    • Hooks no React

      Hooks são uma adição ao React, introduzida na versão 16.8, que permite o uso de estado e outros recursos do React em componentes funcionais. Com Hooks, você pode escrever componentes funcionais que manipulam estado, efeitos colaterais e outros recursos que anteriormente eram limitados a componentes de classe.

      Por que usar Hooks?

      • Reutilização de lógica entre componentes: Facilita o compartilhamento de lógica entre componentes de forma simples.
      • Componentes funcionais mais poderosos: Com Hooks, componentes funcionais podem ter estado e lógica de ciclo de vida.
      • Código mais limpo: Elimina a complexidade de classes e permite código mais legível e direto.

      Tipos de Hooks mais comuns

      • useState: Permite adicionar estado a componentes funcionais.
      • useEffect: Permite lidar com efeitos colaterais, como requisições de dados ou interações com o DOM.
      • useContext: Permite acessar o contexto global do React sem passar props manualmente.
      • useRef: Usado para acessar diretamente o DOM ou persistir valores entre renderizações.
      • useReducer: Útil para manipulação de estados mais complexos.

      Regras dos Hooks

      • Chame Hooks no topo do componente: Não use Hooks dentro de loops, condições ou funções aninhadas.
      • Use Hooks apenas em componentes React: Não use Hooks fora de componentes funcionais ou de funções personalizadas de Hooks.

    • useState no React

      O useState é um dos hooks mais utilizados no React, permitindo que componentes funcionais tenham e manipulem estados. Antes dos hooks, somente componentes de classe tinham essa capacidade.

      Sintaxe básica do useState

      O useState retorna um array contendo dois valores: o valor atual do estado e uma função para atualizar esse valor. 

          
<script>
import React, { useState } from 'react';

function Contador() {
  const [contador, setContador] = useState(0);

  return (
    <div>
      <p>Você clicou {contador} vezes</p>
      <button onClick={() => setContador(contador + 1)}>
        Clique aqui
      </button>
    </div>
  );
}

export default Contador;
</script>

      No exemplo acima, temos um estado chamado contador que é inicializado com o valor 0. Quando o botão é clicado, o valor do estado é atualizado usando a função setContador, incrementando o valor em 1.

      Exemplo com múltiplos estados

      É possível usar múltiplos estados em um componente chamando o useState mais de uma vez. 

          
<script>
import React, { useState } from 'react';

function PerfilUsuario() {
  const [nome, setNome] = useState('João');
  const [idade, setIdade] = useState(25);

  return (
    <div>
      <p>Nome: {nome}</p>
      <p>Idade: {idade}</p>
      <button onClick={() => setIdade(idade + 1)}>
        Aumentar Idade
      </button>
    </div>
  );
}

export default PerfilUsuario;
</script>

      Nesse exemplo, dois estados são declarados: nome e idade. Cada um pode ser manipulado de forma independente.

      Considerações importantes

      • useState deve ser chamado no topo do componente: Não use o useState dentro de loops ou condições.
      • Atualizações de estado são assíncronas: Quando o estado é alterado, o React agenda uma atualização e re-renderiza o componente com o novo valor.

    • Eventos HTML no React

      Em React, eventos são tratados de maneira semelhante aos eventos HTML tradicionais, mas com algumas diferenças importantes, como a nomeação em camelCase e o uso de funções em vez de strings para definir manipuladores de eventos.

      Diferenças principais:

      • Nomeação dos eventos: Em vez de usar onclick, usa-se onClick, e assim por diante.
      • Manipuladores de eventos como funções: No React, você passa uma função para lidar com o evento.
      • preventDefault: No React, você usa event.preventDefault() para evitar o comportamento padrão de eventos.

      Exemplo de clique no botão

          
<script>
import React, { useState } from 'react';

function Saudacao() {
  const [mensagem, setMensagem] = useState('Bem-vindo!');

  const handleClick = () => {
    setMensagem('Obrigado por clicar!');
  };

  return (
    <div>
      <p>{mensagem}</p>
      <button onClick={handleClick}>Clique aqui</button>
    </div>
  );
}

export default Saudacao;
</script>

      Neste exemplo, o estado mensagem é alterado quando o botão é clicado, usando a função handleClick.

      Exemplo de evento de formulário

          
<script>
import React, { useState } from 'react';

function Formulario() {
  const [inputValue, setInputValue] = useState('');

  const handleChange = (event) => {
    setInputValue(event.target.value);
  };

  return (
    <div>
      <input type="text" value={inputValue} onChange={handleChange} />
      <p>Você digitou: {inputValue}</p>
    </div>
  );
}

export default Formulario;
</script>

      No exemplo acima, o campo de texto captura o valor digitado e atualiza o estado inputValue toda vez que o usuário digita.

      Exemplo de preventDefault em formulário

          
<script>
function FormularioPrevent() {
  const handleSubmit = (event) => {
    event.preventDefault();
    alert('O formulário não foi enviado!');
  };

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit">Enviar</button>
    </form>
  );
}

export default FormularioPrevent;
</script>

      Aqui, o envio do formulário é evitado com o uso do método preventDefault(), impedindo o comportamento padrão.

      Eventos suportados pelo React

      • Eventos de mouse: onClick, onDoubleClick, onMouseEnter, onMouseLeave, etc.
      • Eventos de teclado: onKeyDown, onKeyPress, onKeyUp.
      • Eventos de formulário: onChange, onSubmit, onFocus, onBlur.
      • Eventos de janela: onResize, onScroll.
